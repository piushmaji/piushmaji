## About

I started by building full-stack products — React, TypeScript, Supabase, PostgreSQL — shipping applications end to end: APIs, databases, auth, and deployment. That work shaped how I think about systems: not just models, but the infrastructure around them.

My current focus is AI engineering — applying that product and backend foundation to generative AI and retrieval systems. I work primarily in Python, building RAG pipelines, embedding and semantic search workflows, and LLM-backed APIs designed to run as real software, not notebooks.

**Direction:** Backend Engineering → Machine Learning Fundamentals → Generative AI → RAG & Retrieval Systems → Production AI Applications
